# Examples

This folder contains real report output from Maya Production Pipeliner.

```text
example_report.txt
example_report.json
```

Generated by a real Apply run in Maya 2027 (mayapy standalone, Phase 9a report audit).

Scene contained: one production mesh (unique material), one locator, one default-material mesh, one multi-material mesh, one ambiguous group, and one instanced mesh pair.

The reports reflect actual Apply execution:
- eligible objects moved to their target groups (`did_move = true`, `new_long_name` set);
- instanced content preserved as report-only (`can_move = false`, `did_move = false`);
- `schema_version`, `warning_events`, `summary`, and `report_paths` all present.

These files are generated from real runtime behavior, not constructed by hand.
